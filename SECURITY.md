# Security

PersianWriterAgent is an open-source LibreOffice extension and research tool.

## Reporting a security issue

Please do not publish credentials, private documents, personal data, or an exploitable security detail in a public issue.

If the issue may expose sensitive information or affect users' systems, use GitHub's private vulnerability reporting mechanism for this repository when available. Otherwise, contact the repository maintainer through the GitHub profile associated with [@mmyazdanpanah](https://github.com/mmyazdanpanah).

For ordinary bugs that do not contain sensitive information, please use the public [bug report template](https://github.com/mmyazdanpanah/persianwriteragent/issues/new?template=bug_report.md).

## Scope

Security reports are especially useful for problems involving:

- execution of untrusted code or commands
- unsafe file or document access
- credential or API-key exposure
- unsafe network requests
- malicious document content
- privilege or sandbox bypasses
- dependency vulnerabilities with a realistic impact on PersianWriterAgent users

Please include enough information to reproduce the issue safely, while avoiding disclosure of secrets or private user data.
